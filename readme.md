 HerRights — Web Platform

HerRights is a web platform dedicated to women’s rights, awareness, protection, and support. It provides useful information and resources to help women understand their rights and access assistance.

Installation & Setup

1. Clone the project:

git clone https://github.com/SaadZakraoui/Saad.Zakraoui-final-Project-html-css.git

2. Navigate to the project folder:

cd Saad.Zakraoui-final-Project

3. Install dependencies:

npm install

4. Open index.html in your browser or use Live Server in Visual Studio Code.
